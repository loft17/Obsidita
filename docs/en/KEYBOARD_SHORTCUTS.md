# ⌨️ Keyboard Shortcuts Guide

Complete guide to all available shortcuts in **Obsidian Web**. Use these shortcuts to work faster.

---

## 🚀 Global Shortcuts

The following shortcuts work anywhere in the application:

| Shortcut | Action | Description |
|----------|--------|-------------|
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>P</kbd> | **Quick Open** | Open dialog to search and open a note quickly |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>S</kbd> | **Save** | Manually save the current note (normally saves automatically) |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>E</kbd> | **Edit/Read** | Toggle between edit mode and reading mode |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>B</kbd> | **Sidebar** | Show or hide sidebar (explorer, search, etc.) |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>K</kbd> | **Edit with AI** | Open the AI bar on the note or the selection (if configured, see [AI.md](AI.md)) |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | **Search** | Open search panel in sidebar |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + **Wheel** | **Change Font Size** | Zoom in or out the text (similar to browser zoom) |

---

## 📝 Editor Shortcuts

Available when writing in edit mode:

| Shortcut | Action |
|----------|--------|
| <kbd>Tab</kbd> | **Indent** | Indent the current line with a tab |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | **Dedent** | Reduce indentation of the current line |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Z</kbd> | **Undo** | Revert the last change |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Y</kbd> | **Redo** | Redo the undone change |

---

## 🔍 Search & Filter Shortcuts

When using search or filters:

| Shortcut | Action |
|----------|--------|
| <kbd>Escape</kbd> | **Clear** | Empty the search or filter field |

---

## 📂 Dialog & Window Shortcuts

When a dialog is open:

| Shortcut | Action |
|----------|--------|
| <kbd>Escape</kbd> | **Close** | Close the dialog without saving changes |
| <kbd>Enter</kbd> | **Accept/Save** | Confirm the action (save, create, etc.) |
| <kbd>↑</kbd> <kbd>↓</kbd> | **Navigate** | Move between available options |

---

## 📱 Mobile Device Notes

On **mobile devices** or **tablets**, some shortcuts are not available due to soft keyboard limitations. Main shortcuts can be accessed through:

- **On-screen Buttons**: Use icons on the interface for main actions
- **Context Menus**: Long press elements for additional options
- **Pinch Gesture**: Use pinch to change font size (same as <kbd>Ctrl</kbd> + wheel)

## 💡 Helpful Tips

### Most Used Shortcuts
For maximum productivity, master these three first:
1. **Ctrl/Cmd + P** - Open notes quickly
2. **Ctrl/Cmd + E** - Toggle edit/read
3. **Ctrl/Cmd + S** - Save changes

### Customization
Some shortcuts may vary by operating system:
- **macOS**: Use <kbd>Cmd</kbd> instead of <kbd>Ctrl</kbd>
- **Linux/Windows**: Use <kbd>Ctrl</kbd>

### Auto-save
Most changes save automatically. The <kbd>Ctrl/Cmd + S</kbd> shortcut is useful if you want to ensure everything is saved.
